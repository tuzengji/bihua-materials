# 飞手传书

供“你比划我猜”和“传词游戏”使用的共享素材库，适配手机和电脑。

正式地址：<https://shouyulove.cn/flyinghands/>

设计者：王宁静

线上保留公开共建：所有访问者均可浏览、抽题、导出，以及新增、修改共享素材。删除需填写姓名和管理密码；未配置密码时禁止删除。
部署维护见 [`deploy/README.md`](deploy/README.md)。原项目为
[Lynn07160419/bihua-materials](https://github.com/Lynn07160419/bihua-materials)，
服务器部署分支维护在 [tuzengji/bihua-materials](https://github.com/tuzengji/bihua-materials)。

- 素材分类：长盛不衰（诗词、经典词语、经典句子）、引领潮流（梗、歌词），以及星标精选“经典永流传”。
- 支持新增、编辑、删除、搜索、批量粘贴、CSV 导入、多选导出和批量删除。
- “现在玩”支持直接选择题库，随机抽题、显示／隐藏和全屏展示，同一轮不重复。
- 使用原生 HTML、CSS、JavaScript、Node.js 和内置 SQLite，无需前端构建或外部服务。

## 本地启动

需要 **Node.js 24 或更新版本**，无需安装依赖。在项目根目录运行：

```sh
cd web
npm start
```

打开 <http://localhost:3000/>。终端还会打印局域网访问地址，同一 Wi-Fi 下的手机可以使用该地址访问。

默认端口为 `3000`，可用 `PORT=3001 npm start` 更换端口。macOS 也可以双击 `web/启动网页.command` 启动。

首次启动会建立本地数据库，并加入 169 条已整理的素材（含 3 条演示诗词），与仓库中的分类词库一致。数据库保存在 `web/data/`，该目录不纳入版本控制。网页上的修改保存在本地数据库中；仓库词库与初始化数据同步维护。

## 项目文件

- [`web/`](web/)：网页、接口、测试与素材种子数据。
- [`web/README.md`](web/README.md)：完整使用说明、数据备份和接口文档。
- [`题库.md`](题库.md)：按分类整理的当前词库。
- [`题库.csv`](题库.csv)：包含正文、分类和备注等字段的完整词库，可通过网页“导入”直接使用。
- [`传声筒.pptx`](传声筒.pptx)：原始题库课件。
- [`项目计划.md`](项目计划.md)：原始项目计划。
