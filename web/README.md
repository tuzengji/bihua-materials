# 飞手传书

供你比划我猜、传词游戏使用的共享素材网页。手机和电脑均可操作。

## 启动

需要 Node.js 24 或更新版本，无需安装依赖。在本目录运行：

```sh
npm start
```

打开 http://localhost:3000 。终端还会打印局域网地址，手机连接与这台电脑相同的 Wi-Fi 后，使用该地址访问。保持电脑及服务运行；若系统询问本地网络访问，可允许 Node.js 访问本地网络。

也可双击本目录的 `启动网页.command`。停止服务时，在启动的终端按 `Ctrl+C`。

端口已被占用时：

```sh
PORT=3001 npm start
```

## 使用

- 先选大类，再点击对应子分类：长盛不衰包含“诗词、经典词语、经典句子”，引领潮流包含“梗、歌词”。词语和四字成语归“经典词语”，完整句子和谚语归“经典句子”。“经典永流传”是星标精选合集。点击“全部素材”返回总库。
- 关键词搜索作用于当前分类，切换分类时清空搜索；标题右侧的“全部素材”可一键返回完整题库。导出和抽题使用完整的筛选结果，包含尚未展开的词条。
- “所有素材”按梗、歌词、经典词语、经典句子、诗词的顺序分组，用标题与分隔线区分，词条内不重复显示分类标签。默认根据屏幕大小展示完整行，无需上下滑动；点击“展开更多”后可滚动查看其余词条，点击“收起词条”返回一屏展示。
- 点击“添加素材”逐条录入；题目支持换行，可设置分类、备注和经典标记。
- “导入”支持 CSV 文件和一行一题的批量粘贴。CSV 可下载模板，支持 UTF-8 与 GB18030 编码；先预览检查，修正错误后提交。相同类型、相同正文的素材自动去重（忽略首尾及重复空白）。分类“梗”仍兼容旧 CSV 中的“梗句”写法。
- 添加／编辑素材、批量粘贴和“现在玩”的下拉列表使用统一的网页样式，支持鼠标、触屏和键盘选择。弹窗内的列表会根据屏幕空间向上或向下展开；Esc 收起列表，再按一次可关闭弹窗。
- “导出”导出当前筛选结果，支持一行一条 TXT、顿号连接 TXT 和完整 CSV。TXT 将单条正文内的换行合并为空格；CSV 保留正文换行及全部可编辑字段，可再次导入。
- 在总库或任意子库点击“多选”，勾选词条后可“导出所选”或“删除所选”。导出支持同样的三种格式；删除前会列出所选数量和内容，输入姓名／昵称与管理员密码后一次性删除。支持全选当前搜索结果、清空选择；搜索、展开和收起保留已选词条，切换分类会清空选择。
- 每张便签上的“删除”可直接打开权限验证；也可点击素材查看详情后编辑、删除。星星用于标记已经在活动中验证好玩的题目，标记后也出现在“经典永流传”。
- 点击“现在玩”，使用当前分类和搜索结果开始抽题；也可在出题页的网页题库列表直接选择总库、栏目或子库。栏目标题旁显示题数，点击标题即可选用整组题目；缩进项是对应子库。支持方向键、Home／End、Enter 选择，Esc 或点击列表外收起。切换题库会重新准备一轮。每轮不重复，进入和换题时题目均隐藏。全屏时可按 Esc 退出；不支持原生全屏的手机浏览器会使用铺满视口的展示模式。
- 在“现在玩”准备界面按空格开始游戏，第一题保持隐藏；游戏中空格显示／隐藏，右方向键换题。选择下拉列表或填写表单时，空格用于当前控件。两种玩法的提示可在出题页切换。
- 各设备共用一份数据库，页面每 15 秒自动同步，重新切回页面时立即同步。进行中的出题轮次使用快照，不会被其他成员修改素材打断。

初始化题库按网页中最新保存的整理结果同步，共 169 条（含 3 条演示诗词）：梗 32 条、歌词 27 条、经典词语 103 条、经典句子 4 条、诗词 3 条。仓库根目录的《题库.md》提供分类阅读版本，《题库.csv》保留正文换行、分类、标签、备注和经典标记，可直接导入。成员已删除的素材已从初始化数据中移除，修改过的正文和新增歌词也已同步；新建数据库时会使用这份整理结果。已有数据库不会被初始化数据覆盖，也不会重新补回删除项。

## 数据和备份

数据保存在 `data/materials.sqlite`，停止服务后，复制整个 `data/` 文件夹即可完整备份。恢复时，在停止服务的情况下用备份替换此目录。也可导出全部素材的 CSV 作可读备份；CSV 重新导入会生成新的记录 ID 和时间。

可通过 `MATERIALS_DB` 环境变量指定另一份 SQLite 文件。不要同时运行两个服务操作同一个数据文件。

所有访问成员均可新增、编辑、导入和标记经典；仅删除操作（含批量删除）要求每次填写姓名／昵称及管理员密码，后端验证通过才执行。本版本无需账号，部署在本机，不包含计时、计分或跨设备同步出题。

## 删除权限

管理员在 `web/` 目录运行 `npm run admin:password` 设置或更换密码，输入不会在终端回显；更换后重启服务。配置只保存到本机 `data/admin.json`，内容为随机盐和 scrypt 哈希，已排除在 Git 之外。新克隆的项目需要单独配置；未配置时删除接口保持关闭。可用 `ADMIN_AUTH_FILE` 指定其他后端配置文件。

便签、详情、编辑窗口和批量删除共用同一权限验证。姓名／昵称不能为空，密码错误不会删除任何素材。密码框使用掩码，提交或关闭后清空，不保存到浏览器。删除者、词条内容与时间保存在本机 SQLite 的 `deletion_audit` 表中；不提供公开查询接口。

单条与批量 DELETE 请求均需在 JSON 请求体携带 `auth: { name, password }`，姓名和密码不放在 URL 中。仅本次请求授权，不建立免验证会话；同一来源五分钟内十次密码错误后返回 429。其他操作保持开放。

## 检查

```sh
npm test
```

测试使用临时数据库，覆盖持久化、素材 CRUD、组合筛选、共享读写、导入预览与事务、两种文字导出、CSV 解析往返、去重与抽题状态，不修改实际素材库。

## 接口

| 方法 | 地址 | 行为 |
| --- | --- | --- |
| GET / POST | `/api/materials` | 查询 / 新增素材 |
| DELETE | `/api/materials` | 批量删除 `{ "ids": [...], "auth": { "name": "...", "password": "..." } }`；返回 `deleted`、`alreadyDeleted` 数量 |
| GET / PATCH / DELETE | `/api/materials/:id` | 读取 / 更新 / 验证后删除 |
| POST | `/api/materials/import?preview=1` | 预览 `{ "items": [...] }`，不写入 |
| POST | `/api/materials/import` | 校验整批后写入，重复跳过，错误不写入 |
| GET | `/api/materials/export?format=csv` | CSV；也支持 `format=lines`、`format=dunhao` |
| GET | `/api/materials/template` | 导入模板 |

查询和导出共用 `q`、`group`、`type`、`difficulty`、`tag`、`classic` 筛选。PATCH 可携带上次读取的 `updatedAt`，发生并发修改时返回 409，防止覆盖其他成员的更改。
